🎓 PlacementAI — Student Placement Prediction & Career Guidance

PlacementAI is a student career intelligence platform designed to help students understand their placement readiness, identify skill gaps, and follow a personalized roadmap for improving their career opportunities.

The website collects important student information such as CGPA, attendance, backlogs, technical skills, internships, projects, certifications, aptitude performance, and communication skills and generates an indicative placement-readiness score.

⚙️ How to Run

Method 1 — Direct Browser

1. Download or clone this repository.
2. Open the project folder.
3. Double-click "index.html".
4. The website will open in your browser.

Method 2 — VS Code

1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click "index.html".
4. Select Open with Live Server.
5. The PlacementAI website will open in your browser.

📊 Current Prediction System

The current frontend version uses a demonstration weighted calculation to generate the placement-readiness score.

The score considers factors such as:

- CGPA
- Attendance
- Technical skills
- Internships
- Projects
- Certifications
- Aptitude
- Communication
- Backlogs

This is intended as a prototype for demonstrating the website workflow.

Future Version

The demonstration calculation can be replaced with a trained machine-learning classification model using a real student placement dataset.

🎯 Project Objective

The main objective of PlacementAI is to provide students with a single platform where they can:

Predict → Analyze → Improve → Prepare → Track

Students can understand their current preparation level and identify areas that require improvement before applying for placement opportunities.
